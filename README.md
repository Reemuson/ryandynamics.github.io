# Ryan Dynamics Website

Source repository for the Ryan Dynamics website.

**Live site:** https://www.ryandynamics.com.au

Ryan Dynamics provides electronics, embedded firmware, technical drafting, reverse engineering, and related services in Newcastle, NSW.

## Technical overview

The site is a static Jekyll website deployed with GitHub Pages.

Key characteristics:

- Responsive HTML/CSS frontend
- Jekyll templating and content generation
- Minimal client-side JavaScript
- Responsive image generation and optimisation
- SEO metadata, sitemap, structured content, and canonical URLs
- Local Lighthouse performance auditing
