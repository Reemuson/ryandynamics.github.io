That might be measuring something, switching a load, controlling a motor, replacing a failed module, logging data, or making existing equipment easier to use. items: - { label: Useful, text: "This pump needs to turn on when the tank level is low and report a fault if it does not run." } - { label: Less useful, text: "I need an Arduino board with Wi-Fi and a relay." } - title: Information that helps items: - { label: Function, text: "What the device needs to sense, control, display, log, or communicate." } - { label: Power, text: "Battery, plug pack, vehicle supply, solar, mains-derived supply, or existing equipment rail." } - { label: Loads, text: "Motors, solenoids, relays, LEDs, heaters, pumps, or other outputs, including voltage and current if known." } - { label: Signals, text: "Sensors, switches, encoders, serial data, analogue voltages, CAN, RS-485, Wi-Fi, Bluetooth, or other interfaces." } - { label: Environment, text: "Indoor, outdoor, vehicle, workshop, enclosure, vibration, heat, moisture, dust, or chemical exposure." } - { label: Quantity, text: "One-off repair, prototype, small batch, or something intended for repeat production." } - { label: Outcome, text: "What must be demonstrated, fixed, measured, or delivered for the job to be considered successful." } - title: Photos and sketches are valuable body: >- Clear photos, rough sketches, measurements, connector details, and notes from failed attempts are often more useful than a polished document.
