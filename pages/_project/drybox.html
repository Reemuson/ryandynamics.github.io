Many also use a through-spool rod, which slows spool changes and handling. The requirement was an off-the-shelf local container, standard hardware, sealed filament feed, and fast spool access. - title: Constraints & goals items: - { label: Availability, text: "container must be purchasable locally (K-Mart 9 L Dry-Food Container)." } - { label: Cost, text: "common hardware only (608 bearings, PC4-M10 couplers), minimal printed mass." } - { label: Usability, text: "no central rod; spools roll on bearings, quick in/out access, feed through couplers." } - { label: Serviceability, text: "desiccant tub removable and oven/microwave-dryable (PETG body + TPU lid)." } - { label: Capacity, text: "dual 1 kg spools, wider spools supported in later revisions." } - { label: Printability, text: "sensible orientations, reduced waste, no exotic supports." } - title: Solution overview body: >- The box uses side rollers with 608 bearings so spools sit and spin freely. Side rollers are quicker and still feed smoothly. - question: What materials should I print the parts from? answer: PETG or ABS for the desiccant tub, TPU for the snap lid, and PLA/PLA+ is fine for everything else. - question: How often should I dry the desiccant? answer: It depends on use and ambient humidity; re-dry when the hygrometer trends upward or after a spool change in humid weather. - question: What relative humidity should I aim for inside the box? answer: Typically under 20-30% RH for hygroscopic filaments such as Nylon and PETG; for ABS, ASA, and PC, keep it below ambient and stable. - question: Do I need PTFE couplers? answer: Couplers keep the filament path sealed and tidy; you can opt to leave them out if you want to just use the box as a dry container. ---
